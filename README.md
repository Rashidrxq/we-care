# WE CARE — Private Clinic Website

A responsive React + TypeScript clinic website built with Vite, Tailwind CSS, Framer Motion and Lucide React.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Before launch

- Replace all bracketed clinic, doctor, qualification and contact placeholders with verified details.
- Replace placeholder profile imagery and sample review copy with approved assets and verified patient reviews.
- Connect the appointment request form to a secure backend before accepting real patient information. The current form is a front-end demonstration and does not transmit or store submissions.
- Add the clinic's verified address and map embed.
